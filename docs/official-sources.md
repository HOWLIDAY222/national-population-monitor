## 省级门户发现层

`server/data/sources.json` 配置了 31 个省级统计门户，统一使用 `role=portal` 与 `monitorOnly=true`。该层回答“官方门户是否可达、内容是否变化”，并从 HTML 链接中识别人口、公报、年鉴及 Excel/CSV/PDF/JSON 候选资源。候选保存到 `discovered_resources`，通过 `/api/v1/discoveries` 查询；候选仍不能绕过专用解析器、口径定义、校验和发布门禁。

在 2026-07-16 的真实审计及缺口复检中，31 个地区均可达且均有候选资源，共保留 164 条有效候选：25 个门户通过正常 HTTPS，江西、山东、湖南、广西、青海 5 个门户只能通过同域 HTTP 入口降级监测；甘肃省统计局主入口返回 HTTP 412，系统改由同属 `gansu.gov.cn` 的省级官方页面降级监测，并登记其 2025 年统计公报。降级来源不会被记作主入口正常，失败数为 0。该结果是运行时快照，后续应以 `pnpm audit:portals` 的最新输出为准。

## 31省级年度正式数据层

31 个省、自治区、直辖市的 2025 年人口指标均已建立独立 `provincial-annual-population-<regionCode>` 数据集并完成真实采集、关系校验、人工审核和正式发布。来源注册表位于 `server/data/sources.json`，包括 28 个 HTML 公报、2 个 PDF 公报和 1 个旧版 Word 公报。

- 普通 HTML 与可提取文本 PDF 使用严格人口段解析器，只提取公报明确发布的指标，不用总量反推缺失值。
- 广东 PDF 为纯图片文件：人口页经视觉核对后以 PDF SHA-256、页码和原文片段锁定；文件内容变化即停止沿用转录值。
- 青海公报为旧版 Word 文件：使用原始 DOC SHA-256 锁定已复核记录；文件变化后必须重新审核。
- 江西 GB2312 页面使用显式 `gb18030` 解码；新疆“全疆”表述使用来源专属总人口规则，避免扩大通用规则造成误匹配。
- 地方统计局将公报刊载于省级党报或政府转载页时，记录仍以公报署名统计机构为来源机构，并同时保存实际抓取 URL 和复核入口。

## 使用原则

1. 页面发布时间、统计时点、采集时间和平台发布时间分别保存。
2. “2025年末人口”与“2025年11月1日抽样调查人口”不得合并为同一版本。
3. 第六次普查全国合计包含现役军人和难以确定常住地人口；31省合计单独校验为 1,332,774,867 人，并与 6,949,985 人口径差额核对后得到全国合计 1,339,724,852 人。
4. 国家数据查询页面只作为结构化来源候选；未确认稳定接口和使用约束前不依赖非公开内部接口。
5. 每个地方来源必须记录主管机构、URL、检查频率、解析器、许可说明和备用来源。
6. 来源页面结构变化时停止自动发布，保留上一有效版本并产生解析异常事件。
